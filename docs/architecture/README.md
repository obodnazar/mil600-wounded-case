## Рішення для команди

Назар погодив логічні межі й модель за ADR 0002–0005 ([рішення](../decisions.md)): один модульний сервер та реляційне сховище для навчального прототипу; джерельні адаптери з мінімальними подіями; окреме підтвердження людини / випадку; жодного прямого доступу командира до медичних джерел. Включення сервісу до реальної ІКС «Супровід» лишається питанням власникам, а не нашим рішенням про розгортання.

Альтернатива — змінити конкретну межу або сутність до коду. Реальні мікросервіси, брокер, стек і production-хостинг не обираємо без відповідних потреб та погоджень. Стек і фізичні міграції затверджуються у фазі 8а; безпека й пороги розкриття — у фазі 7.
