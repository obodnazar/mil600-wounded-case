## Як відтворити

Запуск і повна перевірка застосунку — [prototype/README](../prototype/README.md). Для документів з кореня: `python3 scripts/verify-final.py`, `python3 research/scripts/check-voices.py`. Валідація XML / DI / round-trip і експорт SVG — [BPMN README](bpmn/README.md). Команди та фактичні результати цього зрізу — [фінальне рев’ю](reviews/final.md).

Друкований файл генерується з тієї самої Markdown-сторінки, без скорочення тексту:

```sh
python3 -m pip install reportlab pypdf
python3 scripts/render-pitch-pdf.py --font-dir /path/to/dejavu-fonts
```

Потрібні `DejaVuSans.ttf` і `DejaVuSans-Bold.ttf`; це зовнішні залежності лише експорту, не застосунку. Перевірка PDF — одна сторінка, витягуваний український текст і візуальний огляд після останньої генерації. Сценарій не підключається до державних систем.

## Що ще потрібно вирішити

Для навчальної здачі: прийняти пакет або назвати конкретні правки; розподілити виступ і провести людську репетицію. До реального пілота: власник сервісу / повноважень, юридичне й медичне погодження правил, дозволені канали, OPSEC / захист / SSO, експлуатаційний план, baseline і дизайн оцінювання. Власники, ресурси, бюджет та строки цих робіт **[TBD]**; оцінок без підстав не додано.

Рішення **А — рекомендоване:** прийняти фінальний навчальний пакет у наведених межах. **Б:** повернути конкретні правки в той самий PR. Після PR — **СТОП**; затвердження не означає автоматичного merge, deployment або надсилання матеріалів іншим людям.
