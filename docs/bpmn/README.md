# BPMN AS IS — комплект фази 4

- [as-is.bpmn](as-is.bpmn) — канонічний BPMN 2.0 XML із DI; редагуйте його в BPMN-редакторі.
- [as-is.svg](as-is.svg) — векторний експорт XML через **bpmn-js 18.31.1**, для перегляду зі збільшенням.
- [Опис, джерела й межі](../03-as-is.md) — обов’язкова частина схеми; `*` позначає припущення / неперевірену нормативну деталь.
- [Рев’ю](../reviews/phase-4.md) та [рішення про порядок фаз](../decisions.md).

## Відкрити й експортувати

1. Завантажте `as-is.bpmn` і відкрийте через **Open diagram** у [bpmn.io](https://demo.bpmn.io/) або локальному редакторі на bpmn-js. Файл містить лише навчальні ролі та описи.
2. Для цілого маршруту використайте **Fit viewport**, для читання — збільшення. Широку схему зручно читати в SVG.
3. Після правок збережіть BPMN XML та повторно експортуйте **SVG** через меню редактора; перевірте обидва файли разом. SVG — похідний файл.

Імпорт / `saveSVG()` описані в [bpmn-js](https://bpmn.io/toolkit/bpmn-js/walkthrough/). Документація без дати публікації, перевірена 2026-11-13. Фактично перевірено локальний bpmn-js Modeler, а не ручне завантаження на публічний demo-сайт.

## Повторити структурну перевірку

Потрібен Node.js із підтримкою ESM та `require()` для ESM-залежності (використано **26.8.2**). Залежності встановлюються поза репозиторієм; це не вибір стеку прототипу.

```sh
qa_dir="$(mktemp -d)"
npm install --prefix "$qa_dir" --ignore-scripts --no-audit --no-fund --save-exact bpmn-moddle@10.3.1
node docs/bpmn/validate.mjs "$qa_dir/node_modules"
```

Запускайте з кореня репозиторію. Скрипт завершується ненульовим кодом за помилки й перевіряє:

- читання та round-trip через [bpmn-moddle](https://github.com/bpmn-io/bpmn-moddle) без попереджень;
- сім доріжок, належність вузлів, посилання, `incoming` / `outgoing`, DI;
- підписи й default-гілки, досяжність вузлів та шлях до завершення;
- межі підпроцесів, ортогональні стрілки без проходу крізь сторонні вузли;
- non-interrupting таймери довідки й контролю тривалого лікування.

Документація bpmn-moddle без дати публікації, перевірена 2026-11-13. Скрипт не є XSD-валідатором, юридичною перевіркою чи повним симулятором BPMN.

Окрема XSD-перевірка за наявності Python із `lxml`:

```sh
python3 - "$qa_dir/node_modules/bpmn-moddle/resources/bpmn/xsd/BPMN20.xsd" docs/bpmn/as-is.bpmn <<'PY'
import sys
from lxml import etree
schema = etree.XMLSchema(etree.parse(sys.argv[1]))
schema.assertValid(etree.parse(sys.argv[2]))
print("BPMN20 XSD: valid")
PY
```

| BPMN20 XSD, Python lxml 6.1.1 | Валідно після нормалізації XML через bpmn-js |

| Сценарний прохід | Без переведення / з повторним переведенням; неповний пакет; неузгоджені формулювання; з родиною / без; контроль строку; ОГД / без; доопрацювання ОГД |

`certificate_due_at` і `long_treatment_review_at` — описові дати без конкретних значень. Формальні вирази валідні у **невиконуваній** моделі; схема не готова до запуску в рушії.
