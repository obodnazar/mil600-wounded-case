## Перевірки та обмеження

- Повторно звірено інструкції, рішення, концепцію, нормативні застереження, AS IS / TO BE, матрицю вимог, ризики й фінальні матеріали. Структурний checker перевіряє локальні посилання та покриття F / AC 10, BR 9, S 9, BO 6, R 22; це не автоматична перевірка смислу кожного речення.
- Переглянуто gateway / схеми, доменні переходи, транзакції, серверні доступи / DTO, локальний запуск, UI та CI. **`npm test`: build і 62/62 Node-тестів; `npm run lint`: пройдено; Playwright: 12/12 у локальному Chrome; `npm audit --audit-level=high`: 0 vulnerabilities.** Тести ізольовані від користувацької SQLite.
- Повторна валідація AS IS / TO BE: XSD валідні; parse / round-trip без warnings; AS IS 45 вузлів / 47 flows, TO BE 118 / 121, 8 DI. Незмінний односторінковий PDF має попередній render / text / visual proof у [першому звіті](final.md).
- `check-voices.py`: 44 записи, 40 груп джерел, 20 новіших / 24 історичних; максимум 22 цитовані слова на джерело. Це локальна перевірка реєстру; повторного масового веб-збору цього проходу не було. Результати попереднього доступу до 137 URL збережені й не оголошені новою перевіркою.
- Повторні спроби прочитати повні тексти [№548-XIV](https://zakon.rada.gov.ua/laws/show/548-14#Text), [№2011-XII](https://zakon.rada.gov.ua/laws/show/2011-12#Text), [постанови №975](https://zakon.rada.gov.ua/laws/show/975-2013-%D0%BF#Text) через веб-інструмент завершилися timeout. **Нову суцільну звірку поточних редакцій не виконано.** Датовані докази попередніх фаз зберігаються; перед реальним використанням потрібна юридична перевірка чинності й застосування.
- Gitleaks по історії та remote quality / CodeQL / secrets перевіряються для нового head; точні результати й SHA — в описі [PR #11](https://github.com/obodnazar/mil600-wounded-case/pull/11).
