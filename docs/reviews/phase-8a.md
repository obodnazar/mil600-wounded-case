## Докази й межі

- `npm ci --ignore-scripts`; `npm test` — **37/37**, `npm run lint`, `npm run build`; `npm audit --audit-level=high` — 0 відомих vulnerabilities на перевіреному lockfile. Докладний перелік тестів — [README](../../prototype/README.md).
- Playwright — **9/9**: чотири панелі desktop / mobile без горизонтального переповнення, навчальний банер, 403 клініці командира / 404 чужому кейсу, definitions-only BO без рядків / total, dev primary / повтор. Вісім [реальних знімків](../../prototype/screenshots/) перевірено візуально; системний шрифт і великі кнопки, без сторонніх font / telemetry requests. Публічну сторінку й скриншоти Армія+ відкрито в браузері для звірки палітри, офіційні assets не копіювалися.
- У DB-тестах нове відкриття файлу й новий сервер / Ingress відтворюють restart, перевіряють nonce / обидва dedupe-ключі; одночасні доставки застосовують одну подію. Збій audit відкочує inbox / домен / задачі / outbox, повтор із новим nonce успішний. Source event не створює grants; невідома особа / нова непроговорена ревізія чекає розбору.
- Мінімальний primary handler **не завершує D1**. Готові definitions / seed не є BO-розрахунком або AC-прийманням. Винагорода / ОГД, календар, повна видача / квитанції / ВЛК / виконання / винятки — [матриця невиконаного 8б](../prototype-8a.md). Малі групи захищені тестом ядра; app до розрахунків не публікує числа взагалі.
- [ADR 0008](../architecture/adr/0008-demo-stack-and-physical-schema.md) називає Node SQLite release candidate, single writer, спільний DB-власник, HTTP-loopback cookie без Secure, демо-вибір будь-якої ролі, локальний env-bootstrap і відсутність production SSO / TLS / encryption / віддаленого незмінного аудиту / backup-restore. Full ASVS L2 не заявлений, production-ризики не прийняті від імені установ.
- Нові зовнішні технічні джерела відкриті 2026-11-13 і перелічені в ADR. Нормативні висновки прийнятих фаз не змінені, нових чисел масштабу / цитат / baseline немає. Дати seed вигадані й не є юридичним обчисленням.
- GitHub Actions: перевірки quality / browser, CodeQL і gitleaks мають пройти на head цього PR; актуальний результат зафіксовано в описі PR. Deployment / автоматичне злиття PR 8а не запускати.

**Вердикт: фаза 8а готова до затвердження стеку й перших екранів.** Затверджені F01–F10 / AC01–AC10 і D1 не скорочені. Наступна дія — PR і зупинка; 8б та решта 9 — лише після нового рішення команди.
