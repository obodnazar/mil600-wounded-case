## Докази й повторна звірка

- Ключові строки й ролі повторно звірено в повних текстах ВРУ: №2011-XII ст.10-1 п.11, Статут ст.260, №402 II п.6.1 і №975 п.23. Саме повне читання №975 виявило пропуск про воєнний стан. [Першоджерело №975](https://zakon.rada.gov.ua/laws/show/975-2013-%D0%BF): акт 2013-12-25, редакція 2025-08-31, повторна перевірка 2026-11-13. Решта правових посилань трасуються до конспектів і перевірки фази 3 від тієї самої дати; всі акти заново у фазі 5 не перечитувалися.
- Повторно відкрито Q16, Q25, Q37, Q42 і Q43 з [реєстру голосів](../../research/voices.md); підтверджено контекст родинної допомоги, наявного супроводу, часткового позитивного рішення й отриманих після оскарження коштів. Не переносили в концепцію імена, частини, діагнози чи нові дослівні цитати. Дати / контекст лишаються прив’язаними до ID; правота сторін не вважалася доведеною.
- Повторне читання Q03 обмежене: web-reader не відкрив RSS, стандартний curl із перевіркою TLS одержав порожню стрічку без записів. Це не спростовує зафіксований у фазі 2 відгук, але повторної верифікації немає. P2 явно посилається на попередню перевірку та зазначає цю межу; його не видаємо за нове інтерв’ю або підтвердження масовості. Початковий Python-запит також не пройшов через локальний набір центрів сертифікації; TLS не вимикали.
- Першоджерела частково недоступні web-reader через timeout / 403 / cache miss; для наведених текстів ВРУ й частини свідчень використано браузер. Метадані та пошукові фрагменти не підміняли релевантний текст. Нових зовнішніх статистичних чисел чи цитат у концепції немає; нормативні числа мають N-ID і дату перевірки.

## Узгодженість і перевірки

- Кожна **F01–F10** має приймання **AC01–AC10** і рядок **T01–T10**; дев’ять сценаріїв **S1–S9** посилаються на визначені функції. Усі ID вузлів матриці звірені з фактичним XML AS IS. Матриця містить біль / умову → крок → норму → BR → функцію → приймання → BO; інфраструктурний вплив на BO позначено як опосередкований.
- Зіставлено F01–F10 з прийнятим ADR А та чотирма панелями фази 8: медик не отримує нового застосунку; командир не створює еПМК і не бачить клінічних записів; супровід не підписує за нього; представник не отримує прав лише через споріднення. Усі інтеграції, підписи та фінансові події навчального прототипу — майбутні моки. C6 виключений, C2 — підгіпотеза; історичний додаток не став поточним baseline чи пітчем.
- Сценарно перевірено паперовий резерв / невідому подію, повтор і невизначене зіставлення, відсутність підтвердження передачі, технічно неповний пакет без блокування направлення, розділення постанови / виконання, повернення / відмову / часткове рішення / підтвердження коштів, відсутність початкової дати та тяжкий стан без входу бійця. Це логічний прохід концепції, не виконання e2e-тестів.
- Перевірено локальні посилання / якорі, ширину Markdown-таблиць, визначення й покриття ID; `git diff --check` і `python3 research/scripts/check-voices.py` проходять. Тимчасова перевірка документів лежить поза репозиторієм; тести, що лише повторюють текст, до проєкту не додавалися.
- BO-1…BO-6 зв’язані з BRD без нових виміряних значень. Відкриті / виключені кейси, зрілість когорти, невідомі причини, знаменники й FTE / робочий час відділені; синтетичний дашборд не підтверджує вплив. Числові targets BRD лишаються пропозиціями, baseline [TBD].
- Перевірено склад змін: тільки документація. BPMN XML / SVG, дослідницькі реєстри, прототип і його залежності не змінено; npm / BPMN-тести незмінених артефактів не запускали. Реальних медичних даних, сканів, приватних контактів, ідентифікаторів частин чи секретів не додано. Запити власникам / людям і повідомлення не надсилалися.

## Що лишається відкритим

Обсяг MVP ще має затвердити команда. Персони — обмежені синтези публічних потреб; інтерв’ю ролей ВЛК / фінансів / медиків / аналітики та користувацьких тестів немає. Не отримані baseline, підтвердження прав / API, словник реальних фінансових джерел, регламент представництва, поля мінімальної службової видимості та production-допуск. Пороги аналітики й технічні контролі визначаються наступними затверджуваними фазами, не вважаються реалізованими.

Рекомендація: **варіант А обсягу фази 5 — F01–F10, чотири панелі, AC01–AC10; B01–B06 у беклозі**. Операційні потреби передані як вимоги до майбутньої архітектури без вибору стеку / БД. Фаза 6 не розпочата. Після відкриття PR — зупинка, без автоматичного злиття PR фази 5.
