## Перевірка результату

- У реєстрі 21 джерело / конспект: усі 10 початкових позицій і 11 доповнень. Дати й URL узгоджені з конспектами, усі редакції не пізніше зрізу. Матриця містить 21 окрему дію з підставою, статусом та власником / умовою.
- Перевірено локальні файли й якорі, структуру Markdown-таблиць, відповідність ID джерел і дій; `git diff --check` проходить. Перевірка реєстру голосів фази 2 продовжує проходити після оновлення навігації.
- Сценарно зіставлено: еПМК / паперовий резерв; адміністративна ініціація; різні ролі довідки; направлення чинного військовослужбовця; належний електронний пакет; доступ командира; стаціонар / лікувальна відпустка / ОГД; мотивоване повернення; відсутність події без автоматичного СЗЧ чи припинення виплат; родич без перевірених повноважень; аналітика без припущення про законність первинного доступу.
- Виправлені BRD і концепція мають явний ADR на затвердження. C6 виключений, C2 лишається підгіпотезою, baseline `[TBD]`, історія не переносилася у пітч. Затверджені BPMN XML / SVG не змінено; додано посилання на уточнення нормативки. Прототип, стек, схема БД та MVP не розроблялися; npm / BPMN-перевірки незмінених артефактів не повторювалися.
- Не додано реальних медичних даних, імен, ідентифікаторів частин, режимних документів, ключів чи сканів. До репозиторію не входять повні тексти НПА або сирі сторінки; лише короткі конспекти / посилання. Повідомлень людям і зовнішніх запитів не надсилали.

## Межі та рішення

Не отримані: внутрішні режимні регламенти, класифікація даних власником, профілі конкретної системи, договори / протоколи обміну, призначення користувачів, API, охоплення та відповідь про структуру цивільних записів / фінансових статусів. Ці прогалини позначені, а не замінені твердженням «заборонено все» або «дозволено все». Перед реальним впровадженням потрібна юридична й технічна перевірка власників.

Команда обирає роль командира / супроводу й межі інтеграцій за [ADR 0001](../architecture/adr/0001-legal-boundaries.md). Рекомендовано варіант А: адміністративна ініціація, медичне авторство №001/о, необхідні службові дані, чинні дозволені канали та позначені симуляції. Варіант Б — окремий обсяг нормативного розширення з власниками змін; його не вважати вже погодженим.

PR #3 злитий після окремого явного дозволу Назара. Фаза 3 завершується окремим PR у `main` і зупинкою; цей PR не зливається автоматично. Наступна невиконана фаза — **5** після нового затвердження; фаза 4 вже затверджена.
