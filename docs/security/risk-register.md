## Реакція на інцидент / відкат

Зупинити спірний adapter / demo route, відкликати сесію / ключ, зберегти мінімальний захищений аудит без body, повідомити призначеному власнику за майбутнім регламентом. Перевірити scope / повтор / джерельну версію, виправити через нову подію й узгоджену звірку, не прямий прихований UPDATE. Лікування / чинний документний процес і право людини не зупиняються через сервіс. Справжнього інциденту не було, повідомлень нікому не надсилали.

Для демо відкат — попередній перевірений commit і reset **лише синтетичного** стану. Після restart модуля транспортні nonce / дедуплікація не стійкі; до підключення доменних ефектів вони мають бути в транзакційній БД. Реальне видалення / restore / збереження доказів погоджує власник; універсальний строк зберігання не вигаданий.

Рекомендовано прийняти лише залишкові обмеження **локального синтетичного показу**, з планами вище. Жоден ризик production не позначено «прийнятий» без рішення належного власника; рішення команди фази 7 ще очікується.
