# Мапінг ASVS L2 і правових вимог

**2026-11-13 · оцінка покриття, не сертифікат.** Версія — **OWASP ASVS 5.0.0**, опублікована **2025-05-30**, [офіційна сторінка](https://asvs.owasp.org/) / [CSV v5.0.0](https://raw.githubusercontent.com/OWASP/ASVS/v5.0.0/5.0/docs_en/OWASP_Application_Security_Verification_Standard_5.0.0_en.csv), відкрито / перев. 2026-11-13. Вимоги позначено повною версією; не змішуємо номери 4.x / 5.x.

[asvs-coverage.json](asvs-coverage.json) містить усі **253** вимоги L1 + L2 із цього CSV, їхній рівень, статус і зв’язок із контролями. Це відтворений підрахунок рядків `L <= 2`, не кількість пройдених перевірок. `app_tested` — є названий у полі `evidence` тест застосунку, що перевіряє саме цю властивість; `module_tested` — доведено лише для security harness; `partial` / `planned` / `not_assessed` не є виконанням ASVS у всьому застосунку. Не стверджуємо повного L2 або «решта не потрібна». Поля з текстом оригінальних вимог не копіювали.

**Оновлення аудиту 2026-11-14.** Реєстр переведено зі scope «security harness» на локальний застосунок. Розподіл 253 вимог: `app_tested` — **23**, `module_tested` — **2**, `partial` — **11**, `planned` — **4**, `not_assessed` — **213** (було 17 / 9 / 2 / 225 без `app_tested`). Статус `app_tested` поставлено лише там, де тест застосунку справді перевіряє властивість; де реалізація є, а тесту немає, — `partial` з поясненням у `note`. Вимогу 4.1.1 знижено з `module_tested` до `partial`: заголовок `Content-Type` реалізовано, але тесту на нього не було й немає. Рівні 43 ID повторно звірено з CSV 2026-11-14; повний перерахунок рядків не повторювався.

Рішення «використовувати тільки синтетичні дані» зменшує ризик студентського показу, але не є висновком про незастосовність усіх правових норм до майбутнього продукту. Допуск / категоризація / profile / retention / реальна OPSEC — блокувальні умови production, не відкладений пункт після його запуску.
