# Мапінг ASVS L2 і правових вимог

**2026-11-13 · оцінка покриття, не сертифікат.** Версія — **OWASP ASVS 5.0.0**, опублікована **2025-05-30**, [офіційна сторінка](https://asvs.owasp.org/) / [CSV v5.0.0](https://raw.githubusercontent.com/OWASP/ASVS/v5.0.0/5.0/docs_en/OWASP_Application_Security_Verification_Standard_5.0.0_en.csv), відкрито / перев. 2026-11-13. Вимоги позначено повною версією; не змішуємо номери 4.x / 5.x.

[asvs-coverage.json](asvs-coverage.json) містить усі **253** вимоги L1 + L2 із цього CSV, їхній рівень, статус і зв’язок із контролями. Це відтворений підрахунок рядків `L <= 2`, не кількість пройдених перевірок. `module_tested` — доведено лише для security harness; `partial` / `planned` / `not_assessed` не є виконанням ASVS у всьому застосунку. Не стверджуємо повного L2 або «решта не потрібна». Поля з текстом оригінальних вимог не копіювали.

| Вимоги v5.0.0 | Зв’язок / межа |
|---|---|

| 8.1.1–8.1.2 | RBAC / правила полів документовані |
| 8.2.1–8.2.3, 8.3.1 | K01; об’єкт, функція, поле на сервері |
| 14.1.1–14.1.2 | Класифікація / retention часткові |
| 14.2.1, 14.3.2 | K05; URL / кеш, часткове покриття |
| 16.1.1, 16.2.1, 16.2.5 | K06; приватність / інвентар аудиту |
| 16.3.2, 16.4.1 | K06; відмови / encoding доведені |
| 16.4.2–16.4.3 | Відокремлений незмінний аудит ще план |

Машинний файл має точні ID / рівні; діапазони в таблиці — коротке групування. ASVS охоплює також автентифікацію, сесії, TLS, кодування, завантаження, конфігурації й інші частини застосунку; відсутній UI / БД / production не можна перевірити одним модулем. У 8а оновити покриття на фактичних компонентах.

## Нормативні межі

Основа — прийняті [N01–N21](../../regulation/README.md), редакції / дати / статуси в конспектах, зріз 2026-11-13. Це проєктний мапінг, не юридичний висновок установи.

| Підстава | Застосування до контролю | Доказ / прогалина |
|---|---|---|
| [№2297-VI](../../regulation/personal-data-2297.md), ст.6, 7, 11, 14, 16, 24 | Мета / мінімум / підстава / роль / захист, метадані також чутливі | K01 / K03 / K06; реальний володілець / підстава / строки [TBD] |
| [№2801-XII](../../regulation/health-secrecy-2801.md), медична таємниця | Діагнози й refs не відкриваються командиру / супроводу | HTTP 403 / явний DTO; джерельний ACL перед кожним реальним читанням ще не підключено |
| [№80/94-ВР](../../regulation/information-security-80.md), чинний режим захисту | Визначити категорію інформації / власника / застосовний захисний режим | K08 / реєстр; не універсальне твердження «достатньо метаданих» / «усім потрібен атестат» |
| [КМУ №712](../../regulation/security-authorization-712.md), порядки / перехідні положення | Авторизація з безпеки / профіль / належний маршрут і оцінка зміни меж | До реальних даних вирішує власник із компетентною безпековою функцією; студентський CI не КСЗІ / авторизація |
| [№851-IV](../../regulation/electronic-documents-851.md), [№2155-VIII](../../regulation/trust-services-2155.md) | Оригінал / КЕП / джерельний ref / фото різні; HMAC лише наш транспорт | K02 / K03; не підпис медичного документа й не автоматичне право |
| [№548-XIV ст.260](../../regulation/internal-service-548.md), [№402](../../regulation/vlk-402.md), [№260](../../regulation/pay-procedure-260.md) | Довідка про обставини травми (додаток 5 до Наказу №402); ролі та окремий підтверджений / попередній строк | [ADR 0006](../architecture/adr/0006-primary-trigger-and-certificate-clock.md), K10; runtime / UI 8б |
| [№411](../../regulation/ehealth-411.md), [№901](../../regulation/document-exchange-901.md) | Дозволений адресний обмін, а не доступ до всього ЕСОЗ | Реальні договори / scope / поля не отримано; моки не обхід |

Рішення «використовувати тільки синтетичні дані» зменшує ризик студентського показу, але не є висновком про незастосовність усіх правових норм до майбутнього продукту. Допуск / категоризація / profile / retention / реальна OPSEC — блокувальні умови production, не відкладений пункт після його запуску.
