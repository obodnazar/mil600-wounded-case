# Як працювати з репозиторієм

## Без git, просто в браузері

1. Відкрий потрібну папку на GitHub.
2. **Add file → Upload files**, щоб завантажити файл (PDF, docx, фото схеми), або **Add file → Create new file**, щоб написати нотатку в Markdown (`.md`).
3. Унизу напиши коротко, що додаєш (наприклад, «Конспект Наказу 402, розділ про строки»), і натисни **Commit changes**.

Редагувати файл: відкрий його → іконка олівця → зміни → **Commit changes**.

## Куди що класти

| Що | Куди |
|---|---|
| Нормативка (посилання, конспект, PDF з zakon.rada.gov.ua) | `regulation/` + рядок у `regulation/README.md` |
| Відповіді опитування (знеособлені) | `research/survey/responses/` |
| Нотатки інтерв'ю (знеособлені) | `research/interviews/` за шаблоном |
| Цифри, статті, дописи з Threads / FB / Telegram | `docs/01-problem.md` (таблиця джерел) або окремий файл у `research/` |
| BPMN-схеми (`.bpmn` з bpmn.io, `.drawio`, PNG) | `docs/bpmn/` |
| Код прототипу | `prototype/` |

## ❗ Правила для публічного репозиторію

Репозиторій бачить будь-хто в інтернеті. Тому **НЕ можна**:

- ПІБ, позивні, телефони, фото людей. Пиши «респондент 1, поранений, 2025».
- Номери, назви, місця дислокації частин і підрозділів, геолокації, дати й місця бойових епізодів.
- Діагнози, конкретні медичні документи, фото довідок, епікризів, постанов ВЛК — навіть із замазаними даними.
- Скріншоти дописів з іменами чи аватарками авторів. Цитуй текст, пиши «військовий, Threads, дата» і давай посилання.
- **Матеріали курсу**: слайди лекцій, стратегію Армія+, внутрішні дослідження, які нам показали на курсі. Вони не для публікації.
- Будь-що з грифом ДСК чи вище або те, що вам передали «тільки для команди».

Якщо сумніваєшся, не завантажуй і напиши в командний чат.

## Позначки в тексті

- **[перевірити]** — гіпотеза або непідтверджений факт.
- **[TBD]** — даних ще немає (наприклад, baseline для метрики).
- Кожна цифра має посилання на джерело.

## Використання ШІ

Курс вимагає позначати все, що зроблено або суттєво доопрацьовано з ШІ. Якщо ти використав ШІ, додай рядок у [docs/ai-use.md](docs/ai-use.md): що зроблено і яким інструментом.
