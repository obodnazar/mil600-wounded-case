# Нормативка

Тут збираємо НПА, які регулюють процес «поранення → ВЛК → виплата». Для кожного акта: посилання на першоджерело, що саме він регулює і що з цього випливає для продукту (бізнес-правило).

Конспекти кладемо окремими файлами: `regulation/<коротка-назва>.md`. Нижче шаблон.

> За лекцією 2: норма → бізнес-правило → вимога → acceptance criteria. І відрізняємо **закон / постанову / наказ** (обов'язково) від **відомчої інструкції** (дізнатися власника) і від **«у нас так заведено»** (кандидат на видалення).
