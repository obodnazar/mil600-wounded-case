## Як читати висновки

**Підтверджено** — текст відкритий, положення й редакція звірені. **Частково** — норма дає рамку, але не готовий дозвіл конкретному новому сервісу. **Не підтверджено** — немає контракту, визначеного складу даних, повноваження чи відповіді власника. Відсутність підтвердження не оголошується забороною.

Матриця розрізняє «дозволено зараз», «потрібна зміна наказу МОУ», «потрібна зміна постанови КМУ або закону», «заборонено» для точно описаної дії. Умовні варіанти й оцінки зміни позначені явно. «Дозволено» означає правову можливість за виконання названих умов; воно не засвідчує, що новий інтерфейс уже введений в експлуатацію.

Конспекти містять: першоджерело → редакція → релевантний пункт → бізнес-правило → перешкода / зміна. Норма, пропозиція команди та припущення про технічну реалізацію не взаємозамінні. Реальних кейсів, діагнозів, документів чи відомостей обмеженого доступу не збирали.
