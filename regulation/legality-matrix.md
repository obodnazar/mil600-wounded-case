# Матриця законності функцій — фаза 3

**Перевірено: 2026-11-13. Фаза 3 затверджена, ADR 0001 — варіант А.** Норми й редакції — у [реєстрі](README.md), розгорнуті висновки — у [межах продукту](legal-boundaries.md). Це проєктна правова оцінка за відкритими джерелами, не погодження юриста / власника системи на production. Прийняття варіанта А не затверджує окремі нормативні розширення чи всі можливі функції матриці. Уточнення незалежної звірки норм **2026-11-14** позначені в комірках і зведені наприкінці.

«Дозволено зараз» стосується **точно описаної дії й умов**, не готовності API або автоматичного надання доступу новому сервісу. Необхідність зміни акта — оцінка для зазначеного варіанта. Договір / протокол обміну, призначення користувачів і допуск системи можуть бути потрібні без зміни закону. Якщо обсяг прав ще не визначений, це вказано; відсутність доказу не прирівнюється до заборони.

## Пакет змін та погоджень

Рекомендовано зберегти core у межах L01, L03–L09, L11, L13, L15 і L20. Для production потрібні регламент кейсу, персональні повноваження, протоколи обміну та захисний допуск; це ще не виконані погодження. L10, L12, L17–L18 — умовні розширення / зміни на окреме рішення. L02, L07, L14, L16 в описаному вигляді до продукту не включати.

**Уточнення аудиту 2026-11-14.** Незалежна звірка норм додала в комірки датовані уточнення; початкові статуси залишено видимими, рекомендований склад core не змінено. Уточнено статуси L03 і L06 (читати як «частково»), L07 (рішення про мінімізацію, а не пряма заборона), L10 і L17 (потрібна також зміна постанови КМУ); доповнено підстави L04, L06, L08, L18. Чи переносити ці уточнення в самі статуси й чи змінюється через L06 обсяг службової проєкції — [питання команді, аудит 2026-11-14]. Постанова КМУ №948 про служби супроводу, на яку спирається уточнення L03, у реєстрі N01–N21 відсутня — див. [README](README.md).
