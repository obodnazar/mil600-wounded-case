# Матриця законності функцій — фаза 3

**Перевірено: 2026-11-13. На затвердженні.** Норми й редакції — у [реєстрі](README.md), розгорнуті висновки — у [межах продукту](legal-boundaries.md). Це проєктна правова оцінка за відкритими джерелами, не погодження юриста / власника системи на production.

«Дозволено зараз» стосується **точно описаної дії й умов**, не готовності API або автоматичного надання доступу новому сервісу. Необхідність зміни акта — оцінка для зазначеного варіанта. Договір / протокол обміну, призначення користувачів і допуск системи можуть бути потрібні без зміни закону. Якщо обсяг прав ще не визначений, це вказано; відсутність доказу не прирівнюється до заборони.

## Пакет змін та погоджень

Рекомендовано зберегти core у межах L01, L03–L09, L11, L13, L15 і L20. Для production потрібні регламент кейсу, персональні повноваження, протоколи обміну та захисний допуск; це ще не виконані погодження. L10, L12, L17–L18 — умовні розширення / зміни на окреме рішення. L02, L07, L14, L16 в описаному вигляді до продукту не включати.

Команда затверджує [ADR](../docs/architecture/adr/0001-legal-boundaries.md) про роль командира й межі джерел, а не законність невідомої production-реалізації. Підстави та технічна реалізація перевіряються окремо; API, угоди й внутрішні регламенти у цій фазі не отримані.
