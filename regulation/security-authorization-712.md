# Постанова КМУ №712: авторизація з безпеки

- Першоджерело: [ВРУ](https://zakon.rada.gov.ua/laws/show/712-2025-%D0%BF).
- Дата акта: **2025-06-18**; редакція за карткою ВРУ: **2026-04-21**.
- Перевірено: **2026-11-13**, повний текст у браузері; прочитані релевантні положення. Статус: **підтверджено текст норми**, не готовність інтеграції.
- Тип: постанова КМУ. ID у [реєстрі](README.md): **N15**.

## Що регулює

Пп.1–2 постанови: порядки авторизації / профілів та перехідні правила КСЗІ. Порядок авторизації пп.1, 5–8: сфера, суб’єкти, види авторизації, оцінювання відповідності цільовому профілю.

## Бізнес-правила для продукту

Перед реальними даними потрібні визначений власник, профіль, оцінка ризиків і належний маршрут авторизації. Додавання медичного сервісу до існуючої системи потребує оцінки зміни її меж.

## Що заважає цифровому процесу / що треба змінити

Чинність старих матеріалів КСЗІ й перехідний маршрут оцінює власник із компетентним органом; студентський PR не є авторизацією або сертифікатом. На моках реальні реєстри не підключаються.

Застосування до конкретних функцій і власники — у [матриці](legality-matrix.md). Висновки про необхідну зміну НПА є проєктною правовою оцінкою, що подається на затвердження; це не офіційний висновок юриста МОУ.
